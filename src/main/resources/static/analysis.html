系统使用须知

目前支持单选题、多选题、填空题、量表题、矩阵题，理论上支持排序题。

单选题

每道题需要设置 n 份问卷里每个选项出现的概率，各选项概率之和应为 100。 如果该选项需要填入文本，则点击「编辑文本答案」。

然后手动输入这道题的回答，每个答案占一行；需要新增答案则点击「添加答案」， 所有答案概率之和应为 100。

多选题

多选题同单选题。

填空题

填空题类似于单选题，点击「编辑文本答案」即可。

量表题

量表题同样是所有选项概率之和为 100。注意不要漏填，后面可能还有未展示的选项。

矩阵题

矩阵题每一行算一道题，一行的概率之和为 100。

份数与耗时

问卷总份数在 1~1000 份之间。可以用一键随机概率按钮快速设置概率。 一千份问卷大约耗时两个半小时。
