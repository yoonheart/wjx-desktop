系统使用须知

目前支持单选题、多选题、填空题、量表题、矩阵题、下拉框题，理论上支持排序题。

单选题

每道题需要设置 n 份问卷里每个选项出现的概率，各选项概率之和应为 100。 如果该选项需要填入文本，则点击「编辑文本答案」。

然后手动输入这道题的回答，每个答案占一行；需要新增答案则点击「添加答案」， 所有答案概率之和应为 100。

多选题

多选题同单选题。

填空题

填空题类似于单选题，点击「编辑文本答案」即可。

量表题

量表题同样是所有选项概率之和为 100。注意不要漏填，后面可能还有未展示的选项。

矩阵题

矩阵题每一行算一道题，一行的概率之和为 100。

下拉框题

下拉框题同单选题：为每个真实选项设置出现概率，概率之和为 100。 列表中第一项「请选择」为占位项，无需配置概率。

份数与耗时

问卷总份数在 1~1000 份之间。可以用一键随机概率按钮快速设置概率。 一千份问卷大约耗时两个半小时。

如何获取 IP 代理

因为问卷星风控，同一个 IP 最多只能刷 12 份问卷，所以想要大量刷问卷，就需要代理 IP。

所谓「代理 IP 提取链接」，就是一个链接，访问它会返回类似下面的内容：

14.116.214.89:44937

把这个链接粘贴到「ip代理」输入框，脚本每次填问卷前都会访问它拿到一个新 IP。

下面以 51 代理为例（没有广告，用这个是因为注册会送 20 元体验金，差不多可以刷几万份问卷）：

1. 打开 51 代理网址：https://www.51daili.com/index/user/promotion/parent_id/29121/code/MFD8ec8n.html 然后点击免费注册
2. 按照要求填写信息注册
3. 因为国家对代理IP安全比较重视，所以需要先实名认证
4. 点击白名单，查看红圈这里的IP地址，将地址填入框里，然后点击添加IP
5. 点击API提取
6. 套餐选送的20积分，提取数量1，你单份问卷需要多长时间这里就选几分钟，这里推荐选5分钟，选择地区这里看你想要问卷是哪个地区给你填，你就选哪里，其余按我选的来就行，再点击生成API链接

8. 最后复制链接，到工具粘贴进去就可以正常使用了
